# DepSentry — Autonomous Open-Source Supply-Chain & CVE Guardian

**Student:** Mukundraj Bhosale | **Course:** Artificial Intelligence (BTCOC701) | **Activity:** CAS Activity-I

DepSentry autonomously audits Python dependency manifests or live public GitHub repositories against **PyPI JSON Metadata** and **Google OSV.dev Batch Vulnerability Feeds**, detects typosquatting and license conflicts, and synthesizes drop-in patched manifests.
